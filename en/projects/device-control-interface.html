Device Control Interface

I made the interface of an industrial device the company uses easier to understand for the operators who use it. During my internship I designed and built the second version.

Company
MAY Fren Sistemleri
Dates
July–August 2026
Role
Intern, design and development

Screen flow

The main screen has five sections. A Support Center was added for reporting problems.

The interface is in use at the company, so I don’t share screenshots. I drew the screens below as simple boxes.

Support Center problem reporting

What was missing in the first version, and what changed?

  • When something goes wrong

    In the first version, when a problem came up the user didn’t know what to do. In the new version they pick the type of problem in the Support Center, write what happened, add the related test reports and save it all as one file.

  • What each screen is for

    It wasn’t clear what the sub-screens were for. In the new version every screen has its own user guide, which opens next to the screen.

  • Manual Test

    In the first version the channels could only be controlled with the Fill and Empty buttons, there was no manual adjustment. In the new version each channel’s target pressure can be set by hand from its gauge.

  • When a test fails

    When a test fails in Product Test, the screen shows where the problem is, a suggested fix and an exploded view of the part.

  • Assistant

    The main screen has an assistant. It shows the device’s current status, it doesn’t answer general questions.

How I worked

First I used the first version the company runs and noted the gaps, and looked at how operators use the device on site and where they got stuck. For each gap I drew what would change on the screen, then built the second version with React, TypeScript, Tailwind CSS, Tauri, Rust and GSAP. I wrote the device logic in Lua and kept it separate from the interface. I tested every change I made on the device itself, and at the end of the internship I presented the new version to the company’s engineers.
